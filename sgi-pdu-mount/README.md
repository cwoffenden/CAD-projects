# Silicon Graphics PDU Mount

Mounting brackets for an Enlogic PDU in an SGI short rack. The PDU mounts with 2x 10mm M5, and 4x 12mm M3 (the rack-side mounts with the standard SGI SEMS).

![Sheet metal bracket](doc/bracket.jpeg)

The bracket can be mounted in the rack's existing holes, at different positions depending on where clearance is needed.

![PDU fitted](doc/bracket-with-pdu.jpeg)
