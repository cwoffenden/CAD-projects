# Roller Shutter Handle Mount

Adapter to directly connect a modern [Zurflüh-Feller](//www.zurfluh-feller.fr) bevel gear to a 1970's 12mm diameter crank handle. The manufacturer can supply all the required couplings and parts, but they either need more space to install (part C800A) or extensive changes to the existing installation (e.g. part D168NG).
