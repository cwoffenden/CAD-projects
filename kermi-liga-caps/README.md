# Finishing Caps for Kermi Liga Shower

Having installed a [Kermi Liga shower](//www.kermi-duschdesign.com/en/de/shower-design/showering/shower-enclosures/profile-shower-enclosure/liga/), I found the aluminium profiles to feel unfinished, simply being open at the top. The manufacturer supplied sticky end caps gave an unsatisfactory finish, so these CNC replacements were designed.
